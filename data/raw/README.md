# data/raw

Immutable source files for this analysis (the supplied Sixt Canada `jobs` and
`cars` CSV exports).

- Never edit, rename, reformat, or delete files here. Write derived data to
  `data/interim/` or `data/processed/` instead.
- The CSVs are proprietary and are intentionally ignored by Git
  (`.gitignore`), so each developer must place them here locally. Only this
  README is tracked.
